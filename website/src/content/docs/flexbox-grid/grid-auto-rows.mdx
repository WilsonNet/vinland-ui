Utilities for controlling the size of implicitly-created grid rows.

| Class | Effect |
| --- | --- |
| `auto-rows-auto` | `grid-auto-rows: auto;` |
| `auto-rows-min` | `grid-auto-rows: min-content;` |
| `auto-rows-max` | `grid-auto-rows: max-content;` |
| `auto-rows-fr` | `grid-auto-rows: minmax(0, 1fr);` |
| `auto-rows-<number>` | `grid-auto-rows: calc(var(--spacing) * <number>);` |
| `auto-rows-[<value>]` | `grid-auto-rows: <value>;` |

## Examples

### Sizing implicit tracks

Use `auto-cols-*` and `auto-rows-*` to size tracks the grid creates implicitly.

<Preview src="grid-auto-rows-0" width={608} height={116} alt="grid-auto-rows: Sizing implicit tracks" live="vex-0" page="grid-auto-rows" />

```odin
if ui.div("grid grid-flow-col auto-cols-fr gap-4") {
    tile("01")
    tile("02")
    tile("03")
}
```
