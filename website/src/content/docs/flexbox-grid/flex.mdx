Utilities for controlling how flex items both grow and shrink.

| Class | Effect |
| --- | --- |
| `flex-<number>` | `flex: <number>;` |
| `flex-<fraction>` | `flex: calc(<fraction> * 100%);` |
| `flex-auto` | `flex: auto;` |
| `flex-initial` | `flex: 0 auto;` |
| `flex-none` | `flex: none;` |
| `flex-[<value>]` | `flex: <value>;` |

## Examples

### Basic example

Use `flex-1` to let an item grow and shrink as needed, ignoring its initial size.

<Preview src="flex-0" width={608} height={116} alt="flex: Basic example" live="vex-0" page="flex" />

```odin
if ui.div("flex gap-4") {
    tile("01", "w-14 flex-none")
    tile("02", "w-64 flex-1")
    tile("03", "w-32 flex-1")
}
```

### Initial

Use `flex-initial` to allow shrinking but not growing.

<Preview src="flex-1" width={608} height={116} alt="flex: Initial" live="vex-1" page="flex" />

```odin
if ui.div("flex gap-4") {
    tile("01", "w-14 flex-none")
    tile("02", "w-64 flex-initial")
    tile("03", "w-32 flex-initial")
}
```

### Auto

<Preview src="flex-2" width={608} height={116} alt="flex: Auto" live="vex-2" page="flex" />

```odin
if ui.div("flex gap-4") {
    tile("01", "w-14 flex-none")
    tile("02", "w-64 flex-auto")

```
