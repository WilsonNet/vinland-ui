Utilities for controlling how grid items are aligned along their inline axis.

| Class | Effect |
| --- | --- |
| `justify-items-start` | `justify-items: start;` |
| `justify-items-end` | `justify-items: end;` |
| `justify-items-end-safe` | `justify-items: safe end;` |
| `justify-items-center` | `justify-items: center;` |
| `justify-items-center-safe` | `justify-items: safe center;` |
| `justify-items-stretch` | `justify-items: stretch;` |
| `justify-items-normal` | `justify-items: normal;` |

## Examples

### Start, center and end

Use `justify-items-*` to align grid items along their inline axis.

### justify-items-start

<Preview src="justify-items-0" width={608} height={184} alt="justify-items: justify-items-start" />

```odin
if ui.div(ui.cx("grid grid-cols-3 gap-4 rounded-lg bg-stripes stripes-violet-500/25", c)) {
    for i in 1 ..= 6 {
        ui.key(i)
        tile(fmt.tprintf("%02d", i), c == "justify-items-stretch" ? "" : "w-14")
    }
}
```
