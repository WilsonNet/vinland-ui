Utilities for controlling the initial size of flex items.

| Class | Effect |
| --- | --- |
| `basis-<number>` | `flex-basis: calc(var(--spacing) * <number>);` |
| `basis-<fraction>` | `flex-basis: calc(<fraction> * 100%);` |
| `basis-full` | `flex-basis: 100%;` |
| `basis-auto` | `flex-basis: auto;` |
| `basis-px` | `flex-basis: 1px;` |
| `basis-3xs` | `flex-basis: 16rem (256px);` |
| `basis-2xs` | `flex-basis: 18rem (288px);` |
| `basis-xs` | `flex-basis: 20rem (320px);` |
| `basis-sm` | `flex-basis: 24rem (384px);` |
| `basis-md` | `flex-basis: 28rem (448px);` |
| `basis-lg` | `flex-basis: 32rem (512px);` |
| `basis-xl` | `flex-basis: 36rem (576px);` |
| `basis-2xl` | `flex-basis: 42rem (672px);` |
| `basis-3xl` | `flex-basis: 48rem (768px);` |
| `basis-4xl` | `flex-basis: 56rem (896px);` |
| `basis-5xl` | `flex-basis: 64rem (1024px);` |
| `basis-6xl` | `flex-basis: 72rem (1152px);` |
| `basis-7xl` | `flex-basis: 80rem (1280px);` |
| `basis-[<value>]` | `flex-basis: <value>;` |

## Examples

### Using the spacing scale

Use `basis-<number>` to set the initial main size of flex items.

<Preview src="flex-basis-0" width={608} height={116} alt="flex-basis: Using the spacing scale" />

```odin
if ui.div("flex gap-4") {
    tile("01", "basis-16")
    tile("02", "basis-32")
    tile("03", "basis-64")
}
```

### Using fractions

<Preview src="flex-basis-1" width={608} height={116} alt="flex-basis: Using fractions" />

```odin
if ui.div("flex gap-4") {
    tile("01", "basis-1/3")
    tile("02", "basis-2/3")
}
```
