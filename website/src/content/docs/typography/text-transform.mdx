Utilities for controlling the capitalization of text.

| Class | Effect |
| --- | --- |
| `uppercase` | `text-transform: uppercase;` |
| `lowercase` | `text-transform: lowercase;` |
| `capitalize` | `text-transform: capitalize;` |
| `normal-case` | `text-transform: none;` |

<Preview src="text-transform-0" width={608} height={316} alt="text-transform: Basic example" />

if ui.div("flex flex-col gap-5") {
    for c in ([]string{"normal-case", "uppercase", "lowercase", "capitalize"}) {

    }
}
