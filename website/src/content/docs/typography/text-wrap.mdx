Utilities for controlling how text wraps within an element.

| Class | Effect |
| --- | --- |
| `text-wrap` | `text-wrap: wrap;` |
| `text-nowrap` | `text-wrap: nowrap;` |
| `text-balance` | `text-wrap: balance;` |
| `text-pretty` | `text-wrap: pretty;` |

## Examples

### Allowing text to wrap

<Preview src="text-wrap-0" width={608} height={128} alt="text-wrap: Allowing text to wrap" live="vex-0" page="text-wrap" />

```odin
if ui.div("w-72") {
    ui.text("Beloved Manhattan soup stand closes", "text-wrap text-2xl font-bold text-gray-950 dark:text-white")
}
```

### Preventing text from wrapping

<Preview src="text-wrap-1" width={608} height={96} alt="text-wrap: Preventing text from wrapping" live="vex-1" page="text-wrap" />

```odin
if ui.div("w-72 overflow-hidden") {
    ui.text("Beloved Manhattan soup stand closes", "text-nowrap text-2xl font-bold text-gray-950 dark:text-white")
}
```
