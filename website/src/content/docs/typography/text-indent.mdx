Utilities for controlling the amount of empty space shown before text in a block.

| Class | Effect |
| --- | --- |
| `indent-<number>` | `text-indent: calc(var(--spacing) * <number>);` |
| `-indent-<number>` | `text-indent: calc(var(--spacing) * -<number>);` |
| `indent-px` | `text-indent: 1px;` |
| `-indent-px` | `text-indent: -1px;` |
| `indent-[<value>]` | `text-indent: <value>;` |
