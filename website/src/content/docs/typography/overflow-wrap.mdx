Utilities for controlling line breaks within words in an overflowing element.

| Class | Effect |
| --- | --- |
| `wrap-break-word` | `overflow-wrap: break-word;` |
| `wrap-anywhere` | `overflow-wrap: anywhere;` |
| `wrap-normal` | `overflow-wrap: normal;` |

## Examples

### Breaking long words

Use `break-all` or `wrap-anywhere` to break words that would otherwise overflow.

<Preview src="overflow-wrap-0" width={608} height={128} alt="overflow-wrap: Breaking long words" live="vex-0" page="overflow-wrap" />

```odin
if ui.div("grid grid-cols-2 gap-6") {
    if ui.div("w-40 rounded-lg bg-gray-50 p-3 dark:bg-white/5") {
        ui.text("Supercalifragilisticexpialidocious", "text-sm text-gray-700 dark:text-gray-300")
    }
    if ui.div("w-40 rounded-lg bg-gray-50 p-3 dark:bg-white/5") {
        ui.text("Supercalifragilisticexpialidocious", "break-all text-sm text-gray-700 dark:text-gray-300")
    }
}
```
