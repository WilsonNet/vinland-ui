Utilities for controlling the thickness of text decorations.

| Class | Effect |
| --- | --- |
| `decoration-<number>` | `text-decoration-thickness: <number>px;` |
| `decoration-from-font` | `text-decoration-thickness: from-font;` |
| `decoration-auto` | `text-decoration-thickness: auto;` |
| `decoration-[<value>]` | `text-decoration-thickness: <value>;` |

## Examples

### Basic example

<Preview src="text-decoration-thickness-0" width={608} height={248} alt="text-decoration-thickness: Basic example" live="vex-0" page="text-decoration-thickness" />

```odin
if ui.div("flex flex-col gap-5") {
    for c in ([]string{"decoration-1", "decoration-2", "decoration-4"}) {
        ui.key(c)
        specimen(c, ui.cx("text-lg font-medium underline decoration-sky-500 underline-offset-4", c))
    }
}
```
