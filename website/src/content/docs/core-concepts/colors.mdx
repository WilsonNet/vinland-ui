The default palette: 26 families with 11 shades each, matching Tailwind CSS v4 converted to sRGB.

## Using colors

Any color utility takes a palette name: `bg-sky-500`, `text-gray-950`, `border-rose-300`, `ring-violet-500`. Add an opacity modifier with a slash: `bg-black/50`, `ring-gray-950/5`.

<Preview src="colors-0" width={608} height={128} alt="Colors: Using colors" />

```odin
if ui.div("flex gap-3") {
    for a in ([]int{100, 75, 50, 25, 10}) {
        ui.key(a)
        ui.text(fmt.tprintf("%d%%", a), fmt.tprintf("flex size-16 items-center justify-center rounded-lg bg-sky-500/%d font-mono text-xs font-semibold text-sky-950 dark:text-white", a))
    }
}
```
