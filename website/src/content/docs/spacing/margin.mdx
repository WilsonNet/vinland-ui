| `m-px` | `margin: 1px;` |

## Examples

### Basic example

Use `m-<number>` utilities like `m-4` and `m-8` to control the margin on all sides of an element.

<Preview src="margin-0" width={608} height={172} alt="margin: Basic example" live="vex-0" page="margin" />

```odin
margin_box("m-8", "m-8")
```

### Adding margin to one side

<Preview src="margin-1" width={608} height={140} alt="margin: Adding margin to one side" live="vex-1" page="margin" />

```odin
if ui.div("flex items-start gap-8") {
    margin_box("mt-6", "mt-6")
    margin_box("mr-4", "mr-4")
    margin_box("mb-8", "mb-8")
    margin_box("ml-2", "ml-2")
}
```

### Using negative values

Prefix a margin utility with a dash to pull an element outward: `-mt-8`.

<Preview src="margin-2" width={608} height={140} alt="margin: Using negative values" live="vex-2" page="margin" />

```odin
if ui.div("flex w-36 flex-col items-center") {
    ui.el("h-16 w-full rounded-lg bg-sky-400/40")
    ui.text("-mt-8", "relative -mt-8 rounded-lg bg-sky-500 px-4 py-3 font-mono text-sm font-bold text-white shadow-lg")
}
```

### Adding space between children

Use `space-x-<number>` and `space-y-<number>` to space children without a gap.

<Preview src="margin-3" width={608} height={116} alt="margin: Adding space between children" live="vex-3" page="margin" />

```odin
if ui.div("flex space-x-4") {
    tile("01")
    tile("02")
    tile("03")
}
```
