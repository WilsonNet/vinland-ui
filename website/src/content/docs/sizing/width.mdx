Utilities for setting the width of an element.

| Class | Effect |
| --- | --- |
| `w-<number>` | `width: calc(var(--spacing) * <number>);` |
| `w-<fraction>` | `width: calc(<fraction> * 100%);` |
| `w-3xs` | `width: 16rem (256px);` |
| `w-2xs` | `width: 18rem (288px);` |
| `w-xs` | `width: 20rem (320px);` |
| `w-sm` | `width: 24rem (384px);` |
| `w-md` | `width: 28rem (448px);` |
| `w-lg` | `width: 32rem (512px);` |
| `w-xl` | `width: 36rem (576px);` |
| `w-2xl` | `width: 42rem (672px);` |
| `w-3xl` | `width: 48rem (768px);` |
| `w-4xl` | `width: 56rem (896px);` |
| `w-5xl` | `width: 64rem (1024px);` |
| `w-6xl` | `width: 72rem (1152px);` |
| `w-7xl` | `width: 80rem (1280px);` |
| `w-auto` | `width: auto;` |
| `w-px` | `width: 1px;` |
| `w-full` | `width: 100%;` |
| `w-screen` | `width: 100vw;` |
| `w-dvw` | `width: 100dvw;` |
| `w-dvh` | `width: 100dvh;` |
| `w-lvw` | `width: 100lvw;` |
| `w-lvh` | `width: 100lvh;` |

| `size-[<value>]` | `width: <value>; height: <value>;` |

## Examples

### Basic example

Use `w-<number>` to set a fixed width from the spacing scale.

<Preview src="width-0" width={608} height={500} alt="width: Basic example" live="vex-0" page="width" />

```odin
if ui.div("flex flex-col gap-3") {
    for w in ([]string{"w-96", "w-80", "w-64", "w-48", "w-40", "w-32", "w-24"}) {
        ui.key(w)
        tile(w, w)
    }
}
```

### Using a percentage

Use fractions like `w-1/2` and `w-2/5`, or `w-full`.

<Preview src="width-1" width={608} height={244} alt="width: Using a percentage" live="vex-1" page="width" />

```odin
if ui.div("flex flex-col gap-3") {
    if ui.div("flex gap-3") {
        tile("w-1/2", "w-1/2")
        tile("w-1/2", "w-1/2")
    }
    if ui.div("flex gap-3") {
        tile("w-2/5", "w-2/5")
        tile("w-3/5", "w-3/5")
    }
    tile("w-full", "w-full")
}
```

### Setting both width and height

Use `size-<number>` to set width and height together.

<Preview src="width-2" width={608} height={192} alt="width: Setting both width and height" live="vex-2" page="width" />

```odin
if ui.div("flex items-end gap-4") {
    for c in ([]string{"size-16", "size-20", "size-24", "size-32"}) {
        ui.key(c)
        tile(c, c)
    }
}
```
