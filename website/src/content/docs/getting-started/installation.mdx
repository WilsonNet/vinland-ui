Add vinland-ui to an Odin project and open your first window.

## Requirements

Odin (dev-2026-11 or newer), SDL3 development files, and Metal (macOS) or Vulkan (Linux) with automatic OpenGL 3.3 fallback. Fonts and icons are embedded, so there is nothing else to install.

```sh
# macOS
brew install odin sdl3
# Arch
sudo pacman -S sdl3
# Debian / Ubuntu
sudo apt install libsdl3-dev
```

## Add the packages

Clone the repository next to your project (or as a git submodule) and import the packages by path, or register a collection with `-collection:vinland=path/to/vinland-ui`.

```sh
git clone https://github.com/WilsonNet/vinland-ui
odin build my_app -collection:vinland=vinland-ui
```

## A first window

```odin
package my_app

import ui "vinland:vui"
import "vinland:vui/app"
import "vinland:vui/fonts"

main :: proc() {
    ctx: ui.Context
    ui.init(&ctx)
    defer ui.destroy(&ctx)
    fonts.register(&ctx)

    a: app.App
    if !app.init(&a, {title = "Hello", size = {960, 640}, control_port = 7420}, &ctx) do return
    defer app.shutdown(&a)

    for app.next_frame(&a) {
        if ui.div("flex h-full items-center justify-center bg-white dark:bg-gray-950") {
            ui.text("Hello from Odin", "text-4xl font-semibold tracking-tight text-gray-950 dark:text-white")
        }
        app.end_frame(&a)
    }
}
```

## Or describe the app as a Program

`app.run` takes the same app as callbacks and owns the context, window and loop. It builds and runs exactly like the loop above, and it is what lets `vui-hot` reload the code without closing the window (see Hot reload).

```odin
State :: struct { count: int }
s: State

main :: proc() {
    app.run({
        config = {title = "Counter", size = {480, 320}},
        setup  = proc(a: ^app.App) { fonts.register(a.ctx); app.keep(&s) },
        frame  = proc(a: ^app.App) {
            if ui.button(fmt.tprintf("Clicked %d times", s.count), "rounded-lg bg-sky-600 px-4 py-2 text-white") {
                s.count += 1
            }
        },
    })
}
```

## Bring your own renderer

Games that already own a render loop (raylib, Vulkan, Metal, a custom engine) can skip `vui/app`: call `ui.begin_frame` with your input, build, call `ui.end_frame` and draw the returned `Draw_List`. Each command is one instanced quad; `vui/app/shaders/` (GLSL and MSL) and `vui/app/gl.odin` are the reference implementations of the uber-shader.
