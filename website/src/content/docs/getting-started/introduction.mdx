vinland-ui is a utility-first UI framework for Odin. You write UI in Odin, style it with Tailwind-style classes that resolve through design tokens, and a GPU renderer draws it at your display's real pixel density.

        }
    }

    }

## What it is

A small set of Odin packages. `vui` holds the element tree, the utility parser, design tokens, layout, text shaping and painting. `vui/app` is a host built on SDL3 GPU (Metal on macOS, Vulkan on Linux) with an OpenGL 3.3 fallback that owns the window, input and the control server. `vui/sdlgpu` draws vui inside another program's SDL3 GPU render pass (games), and `vui/gl` + `vui/raylib` do the same for OpenGL/raylib hosts. `vui/fonts` embeds Inter, IBM Plex Mono and Source Serif 4, and `vui/icons` ships Heroicons.

The core never draws anything on its own. A `ui.div` is an empty box until you give it classes, so the look of an app lives entirely in your code and in your theme.

## How it reads

Containers open with `if ui.div("...") { }` and close automatically at the end of the block. Leaves such as `ui.text`, `ui.icon` and `ui.el` take a class string. Interaction is queried where you build: `ui.clicked()`, `ui.hovered()` and friends refer to the element you are inside.

```odin
count := 0
for app.next_frame(&a) {
    if ui.div("flex h-full items-center justify-center bg-gray-50") {
        if ui.button(fmt.tprintf("Clicked %d times", count), "rounded-full bg-gray-950 px-4 py-2 text-sm font-semibold text-white hover:bg-gray-800") {
            count += 1
        }
    }
    app.end_frame(&a)
}
```

## Inspiration

Jetpack Compose showed that UI can live in the host language. Flutter showed the value of owning the renderer end to end. Quickshell showed how good small desktop widgets can feel when animation is cheap. Tailwind CSS supplied the vocabulary: if you know Tailwind, you already know how to style vinland-ui.
