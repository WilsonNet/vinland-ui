Utilities for controlling the alignment of a caption element inside of a table.

| Class | Effect |
| --- | --- |
| `caption-top` | `caption-side: top;` |
| `caption-bottom` | `caption-side: bottom;` |
| `"Stone Cold" Steve Austin` | `Stone Cold Stunner, Lou Thesz Press` |
| `Bret "The Hitman" Hart` | `The Sharpshooter` |
| `Razor Ramon` | `Razor's Edge, Fallaway Slam` |
| `"Stone Cold" Steve Austin` | `Stone Cold Stunner, Lou Thesz Press` |
| `Bret "The Hitman" Hart` | `The Sharpshooter` |
| `Razor Ramon` | `Razor's Edge, Fallaway Slam` |

:::note
vinland-ui parses these classes so markup ports cleanly between projects, but the native renderer does not draw this property yet. Unknown or unsupported utilities never crash: they are reported by `vui-ctl info` under `unknown_classes` when they fail to parse.
:::
