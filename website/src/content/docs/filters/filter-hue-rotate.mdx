Utilities for applying hue-rotate filters to an element.

| Class | Effect |
| --- | --- |
| `hue-rotate-<number>` | `filter: hue-rotate(<number>deg);` |
| `-hue-rotate-<number>` | `filter: hue-rotate(calc(<number>deg * -1));` |
| `hue-rotate-[<value>]` | `filter: hue-rotate(<value>);` |

## Examples

### Color filters

Color filters compile into a 4×5 color matrix applied by the shader to the element and its children: `grayscale`, `sepia`, `invert`, `brightness-*`, `contrast-*`, `saturate-*`, `hue-rotate-*`.

<Preview src="filter-hue-rotate-0" width={608} height={352} alt="hue-rotate: Color filters" live="vex-0" page="filter-hue-rotate" />

```odin
if ui.div("grid grid-cols-4 gap-4") {
    for c in ([]string{"", "grayscale", "sepia", "invert", "brightness-125", "contrast-150", "saturate-200", "hue-rotate-90"}) {
        ui.key(c)
        if ui.div("flex flex-col items-center gap-2") {
            ui.image(DEMO_IMAGE, ui.cx("size-28 rounded-lg object-cover", c))
            ui.text(c == "" ? "none" : c, "font-mono text-xs text-gray-500 dark:text-gray-400")
        }
    }
}
```
