Utilities for applying blur filters to an element.

| Class | Effect |
| --- | --- |
| `blur-xs` | `filter: blur(var(--blur-xs));` |
| `blur-sm` | `filter: blur(var(--blur-sm));` |
| `blur-md` | `filter: blur(var(--blur-md));` |
| `blur-lg` | `filter: blur(var(--blur-lg));` |
| `blur-xl` | `filter: blur(var(--blur-xl));` |
| `blur-2xl` | `filter: blur(var(--blur-2xl));` |
| `blur-3xl` | `filter: blur(var(--blur-3xl));` |
| `blur-none` | `filter: ;` |
| `blur-[<value>]` | `filter: blur(<value>);` |

:::note
vinland-ui parses these classes so markup ports cleanly between projects, but the native renderer does not draw this property yet. Unknown or unsupported utilities never crash: they are reported by `vui-ctl info` under `unknown_classes` when they fail to parse.
:::
